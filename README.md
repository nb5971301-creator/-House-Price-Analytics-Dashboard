#  House Price Analytics Dashboard

##  Project Overview

The **House Price Analytics Dashboard** is an interactive data visualization project developed using **Microsoft Power BI**. It provides insights into house prices based on location, property condition, number of bedrooms, area, and year of construction.

The dashboard helps users explore housing data, compare average prices, identify price variations, and understand the factors that influence house prices.

##  Project Objectives

- Analyze house prices across different locations.
- Calculate key housing price statistics.
- Compare average prices based on property condition.
- Analyze the relationship between bedrooms and average house prices.
- Explore the relationship between house area and price.
- Understand house price variations by year of construction.
- Create an interactive dashboard using Power BI.

##  Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Data Visualization** – Charts, slicers, and interactive filters

##  Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard displays four important metrics:

- **Total Houses:** 6K
- **Average House Price:** 537.68K
- **Maximum House Price:** 1000K
- **Minimum House Price:** 50K

### 2. Average Price by Location

Compares average house prices across four locations:

- Suburban
- Rural
- Downtown
- Urban

### 3. Average Price by Condition

Analyzes average house prices across different property conditions:

- Excellent
- Fair
- Good
- Poor

### 4. Average Price by Bedrooms

Compares average house prices for properties with 1 to 5 bedrooms.

### 5. Area vs. Price Analysis

Uses a scatter plot to explore the relationship between house area and price.

### 6. Average Price by Year Built

Displays price variations based on the year the property was built.

### 7. Interactive Filters

Users can filter the dashboard by:

- Location
- Property condition
- Number of bedrooms
- Garage availability

## Dataset Information

The project uses housing data containing the following fields:
Id - Unique house identification number
Area - Size of the house
Bedrooms - Number of bedrooms
Bathrooms - Number of bathrooms
Floors - Number of floors
YearBuilt - Year the house was built
Location - Location of the house
Condition - Condition of the house
Garage - Garage available or not
Price - Price of the house
